# Как мы искали ботов

Задача: по событиям внутри суточного окна дать каждой `cookie_id` оценку от 0 до 1. Чем выше оценка, тем вероятнее автоматический сбор объявлений. Главная метрика: Precision при Recall не ниже 70%. События за концом окна в признаки не попадают.

## Результат

Итоговый ответ лежит в `output/submission.csv`. Это среднее рангов трёх CatBoost без User-Agent: на базовых признаках, с маршрутами между событиями и с контекстом просмотров. На трёх временных проверках средний P@R70 равен **0,566**. Среднее исходных оценок дало **0,558**, лучший отдельный CatBoost получил **0,536**. На последних днях среднее рангов дало **0,622** против **0,605** у среднего оценок. Качество на скрытом test неизвестно.

Модели обучаются только на более ранних днях, чем проверочный отрезок. Каждая модель ранжирует куки внутри проверочного отрезка, а в итоговом файле внутри всего test. Потом усредняем три процентильных ранга. Веса равные, их не подбирали по валидации. Итоговый `score` пригоден для ранжирования, но не является вероятностью: он зависит от состава партии кук.

## Как повторить

Нужен Python 3.12. Из корня проекта установи библиотеки и запусти скрипт:

```bash
python3 -m pip install -r requirements.txt
python3 run_solution.py
```

Скрипт заново читает `data/train.csv`, `data/test.csv` и `data/events.csv.gz`, строит признаки, обучает три модели и создаёт `output/submission.csv`. Для самого файла с ответом промежуточные таблицы из `output` не нужны. Но они нужны для сравнений в начале заключительного ноутбука и уже приложены к репозиторию.

## Что лежит в папках

- `notebooks/01_eda.ipynb`: данные, графики и продуктовый смысл задачи.
- `notebooks/02_baseline.ipynb`: первый простой ориентир.
- `notebooks/03_models.ipynb`: сравнение логистической регрессии, случайного леса и CatBoost.
- `notebooks/04_feature_engineering.ipynb`: ритм действий, маршруты и разнообразие.
- `notebooks/05_item_journeys.ipynb`: история объявлений, контекст и проверка отбора признаков.
- `notebooks/06_conclusion.ipynb`: сравнение ошибок, смешивание моделей и итоговый ответ.
- `notebooks/07_pointer_location.ipynb`: проверка координат курсора и города объявления. Новый кандидат получил 0,725 на временной валидации против 0,566 у текущего ответа. `output/submission.csv` пока не обновляли.
- `notebooks/08_single_full_model.ipynb`: проверка одной CatBoost с новыми признаками. Отобранный набор дал 0,716, все 108 признаков дали 0,696. Ответы этих моделей лежат отдельно в `output/single_context_submission.csv` и `output/single_full_submission.csv`; текущий `output/submission.csv` не меняли.
- `notebooks/quickstart.ipynb`: пример из исходного набора данных.
- `utils/`: расчёт признаков и официальная метрика; `tests/`: проверки границ суточного окна.
- `data/`: исходные файлы; `output/`: предсказания и таблицы для сравнения.

Ноутбуки можно открыть из корня проекта или из `notebooks/`. В начале каждого рабочая папка переключается на корень, чтобы пути к данным и результатам оставались одинаковыми.

Использованы локально запускаемые библиотеки NumPy, pandas, scikit-learn и CatBoost. Их точные версии указаны в `requirements.txt`. Внешние API и большие языковые модели не использовались.
